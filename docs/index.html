強化の成否確率について

装備強化における成功・維持・下降確率について、どのような計算に基づいて算出されているのかは公開されていません。

そのため、このツールでは推測された数式により確率の計算を行います。 +(n - 1) から +n への強化の成功確率 S、維持確率 K、下降確率 D は以下のように算出します。 

			S = Math.round(88 * Math.pow(0.91, n - 1))
			if (n == 1) {
				K = 100 - S
				D = 0
			} else {
				F = 100 - S
				K = Math.round(F * 0.55)
				D = F - K
			}

この計算方法は、少なくとも n が 19 以下のとき、正しい値を求められることが確認されています。

消費ゴールドについて

強化時の消費ゴールドは、武器は 3000 × (強化レベル) G、 防具は 1500 × (強化レベル) G として計算します。
